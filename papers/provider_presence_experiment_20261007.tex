\title{Non-Generative Endpoint Monitoring for Free-Model Agent Fleets:\\
Baseline Measurements and a Prospective Validation Protocol}
\author{Fleet Experiment Working Draft}
\date{October 7, 2026}
\begin{document}
\maketitle
\begin{abstract}
Free language-model endpoints may expose healthy catalogs even while
generation is throttled. We implement separate metadata-only presence checks
and model-attributed inference traces. On an x1-370 pilot, five of eight
catalog, health, or CLI checks were reachable, two direct providers lacked
credentials, and a local OmniRoute dashboard was unavailable. No model
generation was requested by the monitor. A read-only scan of two distinct
OpenCode SQLite databases found 49 unique sessions over one day and one orphan.
This baseline establishes instrumentation, not statistically significant
improvements in inference availability or quality.
\end{abstract}
\section{Problem and Prior Work}
OpenRouter documents a separate public model catalog from completions
\cite{openrouter}; Cohere similarly exposes an authenticated model-list API
\cite{cohere}. xAI publishes token-based API prices \cite{xai}; free consumer
chat access is not proof of free developer API eligibility.
Catalog success is therefore a \emph{metadata presence} signal only.
\section{Methods}
The monitor performs a bounded GET or CLI version check for one endpoint per
configured provider and persists no response bodies or credentials. Request
intervals are 15 minutes for local surfaces and 30 for remote catalogs;
429/503 responses suppress requests for at least one hour and 401/402/403 for
24 hours. Independent model-generation canaries require explicit guarded
admission, final manifests, exact model attribution, and verified zero cost.
The token census uses read-only SQLite with session-ID deduplication across
the account and isolated runtime databases; incomplete sessions remain
incomplete.

\section{Observed Baseline}
On October 7, OpenRouter catalog, Kilo anonymous catalog, auto-router health,
LM Studio catalog, and OpenCode CLI checks succeeded. Direct Cohere and xAI
had no usable monitor credentials. The default OmniRoute health address was
unreachable. Monitoring itself generated zero model tokens. A separately
guarded StepFun canary produced 805 output and 10,973 input tokens in 15.01
seconds, but its engineering review conclusion was rejected as unsupported.
The dual-database census counted 49 distinct recent sessions and one orphan
with a missing clean stop. These are observations, not claimed predictions.

\section{Prospective Hypotheses and Acceptance}
The baseline preceded this protocol; no retrospective preregistration is
claimed. For the \emph{next} observation window we predict (H1) cached checks
make zero requests until each provider's next due time; (H2) a 429 on one
provider does not generate a retry storm on others; (H3) all presence polls
continue to consume zero inference tokens; and (H4) the census preserves
identities from both databases. Acceptance requires raw timestamps, response
codes, timeouts, manifest hash evidence, independently inspected procedural
quality, and tests for interval and cooldown enforcement. No unattended
generation or paid provider fallback is authorized.

\section{Follow-on Observation: October 7, 2026}
After specifying H1--H4, we installed a persistent, read-only systemd user
timer on x1-370 at a 15-minute cadence. The service was observed to return
exit status 0 and was configured to run a private copy of the monitoring
script outside the temporary Git worktree. Remote catalog checks remain
bounded to one request per endpoint every 30 minutes. Local tests
successfully exercised independent per-provider cooldowns, without using
generation APIs. The subsequent focused suite passed 45 tests.

A guarded Kilo admission preflight now requires a fresh, privately owned
provider-state snapshot and conservative local usage evidence from both
OpenCode databases. Sessions are deduplicated and a 15-minute gate accounts
for recently updated sessions' lifetime usage. A separate historical
session remained orphaned, with 2,648,964 input tokens and a last finish
reason of tool-calls, illustrating why final trace quality must not be
inferred from model or catalog availability. No additional generation run
was performed for this follow-on experiment. The original hypotheses
were supported by local tests and monitoring checks only; a multi-day
unattended reliability trial has not yet been completed.

\section{Limitations}
One healthy catalog does not prove availability of any model. Credentials
and upstream quota entitlement remain unknown for some providers.
The installed user timer does not guarantee a successful network connection
or maintain a continuous model session. Observed recent-token totals may
overestimate usage because they count entire lifetimes of sessions updated
within the window. Both admission gates are local to one machine and do not
supply fleet-wide atomic reservations; independent clients and hosts can
still exceed a shared upstream provider limit.
\section{Transactional Lease Pilot: Prospective Slice}
The preregistered protocol for the next slice was recorded in
\texttt{docs/shared\_provider\_lease\_prospectus\_20261007.md} prior
to the offline trial. A private local SQLite coordinator used
\texttt{BEGIN IMMEDIATE} to serialize independent writer transactions
\cite{sqlite}. This is a cooperative one-host admission mechanism and
does not supersede the independent runtime gate in the live auto-router.
The prototype groups the Kilo aliases into one upstream quota domain;
unknown aggregators are deliberately rejected rather than granted
additional quota.

On October 7, twenty simultaneous clients attempted to reserve a
single slot using two aliases. The reproducible trial reported
one accepted and nineteen denied leases, maximum concurrent active
leases of one, twenty-four chained audit events, and 1.1614 seconds of
elapsed test time. Retrying the original request key did not produce
a second lease. A synthetic HTTP 429 opened a provider-specific
3600-second circuit, consistent with its rate-limiting semantics and
optional \texttt{Retry-After} guidance \cite{rfc6585}. No network
generation calls were made and no inference tokens were consumed.
The combined focused regression suite passed 56 tests, including
a separate eight-process contention case and a renewal test that
prevents accidentally shortening an active lease.

These results validate the transactional ledger's offline behavior,
not fleet-wide safety or actual free-model availability. The audit
chain is locally tamper-evident only and lacks external attestation;
leases are cooperative and an expired worker must stop itself. We
have not deployed authenticated cross-node transports or replaced
runtime routing admission, and no claim of zero real-world quota
violations follows from these synthetic observations.
